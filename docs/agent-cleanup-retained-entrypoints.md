The bootstrap module is not wired into an application request. `prepareDemoAccountConnection` performs a single explicit SDK hosted setup request and returns an uncertain outcome without retrying. `verifyDemoAccountBindings` verifies current owned account bindings and returns proposed registry metadata; it does not register accounts, grant sending authority or dispatch messages. Existing tests cover those boundaries, normal Unipile capabilities without invented durable idempotency, mismatched wire identity/generation/capabilities/duplicate accounts, and rejection when a testing profile is not ready for the GUI actor.

The private bootstrap consumers were inspected structurally without executing them or copying their contents. Their presence is a retention dependency, not current account-readiness or operational acceptance evidence. A future relocation/removal must first replace or retire those exact consumers, preserve the unknown-outcome and original-binding checks, and repeat the bootstrap characterization suite.

C03 retired obsolete `apollo-client`, `firmable-people-sync`, `company-website-fallback`, `accreditation-contact-capture`, `conversation-decision` and `merge-targets` helpers after checking application, worker, script, testing and operator consumers. Historical plans and research-correctness evidence retain their original paths; the dated cleanup progress entry supersedes those historical references. Active ABN, public research, accreditation and native-decision replacements remain in place.

Verification for this retention disposition: `node node_modules/vitest/vitest.mjs run src/lib/agent-demo-account-bootstrap.test.ts` passes all five existing tests before and after the explanatory source comment and this inventory were added. No bootstrap was invoked against a service or database. The continuation changes no runtime behavior; an artificial failing test is not appropriate for this documented retention decision. Full local/live acceptance and unrelated full-suite failures remain tracked separately in the cleanup issue and progress record.
