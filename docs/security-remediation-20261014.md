## Additional report candidates

Application session lookup now checks current membership for both user and active organization on every call, returning null after revocation or membership-query failure. Other Better Auth sessions can retain stale organization IDs after member removal; the application must not treat that cached ID as authorization. Tests cover removed/current membership, repeated lookup, no active organization, signed-out access, repository failure and exact query scope. This is local synthetic verification, not a new production membership-removal experiment.

Campaign tick returns a generic500; outreach drafting returns a generic502 and omits raw provider exception text from logs. Regression tests inject synthetic private exception contents and prove they are absent from responses/logs.

Personal-domain email remains a product-policy question, not an authorization defect demonstrated by the original report. The report's current secret candidates were fixtures/placeholders; historical validity/rotation is not established. Scanner parsing gaps, complete authenticated role/tenant/provider tests and other original coverage gaps are not converted into security guarantees by these fixes.
