# Synthetic research fixtures

Executable minimized fictional inputs and expected outcomes are colocated in the test files named by `../acceptance-scenarios.json`. This directory remains available for shared data files; an empty fixture directory is not evidence of a missing test or a passing one.

New shared fixtures should include covered scenario IDs, independently authored expected outcomes and the boundary exercised. Vary geography, industry, scope, legal relationships and operation ordering. Keep provider shapes realistic and exclude production personal data, secrets and raw incident snapshots.
